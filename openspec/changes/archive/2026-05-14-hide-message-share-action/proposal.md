# 隐藏消息分享按钮

## 背景

用户要求暂时隐藏消息工具栏中的分享 icon，并明确要求保留代码，不直接删除。

## 目标

- 从 assistant 消息工具栏中隐藏分享按钮。
- 使用代码注释保留原 JSX，便于后续恢复。
- 不影响复制、点赞、点踩和反馈提交逻辑。

## 非目标

- 不删除分享相关 icon import 之外的业务能力。
- 不新增运行时开关或配置项。
- 不改造消息渲染、反馈接口或线程加载逻辑。

## 影响范围

- 前端消息工具栏组件：`frontend/src/components/workspace/messages/message-list-item.tsx`。

## 风险与约束

- 本次仅隐藏入口；如果未来需要恢复，取消对应 JSX 注释即可。
- 当前 Cursor MCP 列表未暴露 GitNexus 工具；实施前会按静态调用边界评估影响。
