# 隐藏工作区智能体菜单

## 背景

用户要求隐藏左侧工作区导航中的“智能体”菜单，并明确要求通过代码注释保留原实现，不直接删除。

## 目标

- 从工作区左侧导航中隐藏“智能体”菜单项。
- 保留原 JSX 代码，以注释形式留在文件中，便于后续恢复。
- 不影响“对话”菜单、最近对话列表或现有智能体路由实现。

## 非目标

- 不删除智能体页面、路由、API、i18n 文案或业务逻辑。
- 不改变自定义智能体相关数据结构和后端接口。
- 不新增运行时开关或配置项。

## 影响范围

- 前端工作区左侧导航组件：`frontend/src/components/workspace/workspace-nav-chat-list.tsx`。

## 风险与约束

- 直接访问 `/workspace/agents` 相关路由仍可能可用；本次仅隐藏左侧菜单入口。
- 由于当前 Cursor MCP 列表未暴露 GitNexus 工具，实施阶段如无法运行 impact analysis，需要记录为工具约束。
