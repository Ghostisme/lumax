# 智能投流按钮高亮切换

## 背景

用户要求输入区“智能投流”按钮支持点击后高亮，再次点击取消高亮，用于表达该入口的临时选中状态。

## 目标

- “智能投流”按钮点击后切换为高亮态。
- 再次点击同一按钮时取消高亮，恢复默认态。
- 仅调整前端输入框按钮交互与样式，不改变提交消息、线程上下文或后端接口。

## 非目标

- 不新增持久化设置。
- 不联动其他入口按钮。
- 不修改智能投流业务请求链路或提示词。

## 影响范围

- 前端输入区组件：`frontend/src/components/workspace/input-box.tsx`。

## 风险与约束

- 本次状态为组件内本地 UI 状态，切换线程或刷新页面后不保留。
- 当前 Cursor MCP 列表未暴露 GitNexus 工具；实施前会尝试使用可用 CLI 做影响分析，若不可用则记录为工具约束并按静态范围评估。
